# 0061：连接器页读取的持久领取与租约

日期：2026-10-07。状态：手动页读取、首次页取消及租约恢复已实现。

复用 ConnectorSyncCursorV1 增加 reading、read_claim_id 和 read_lease_until，不新增任务表。每页读取先在授权写事务比较原游标和当前配置，增加逻辑 attempt version，保存随机领取身份及 90 秒租约。事务结束后才调用 Reader。首次页因此也有持久状态，能够查看和取消；同一游标的未过期领取拒绝重叠读取。

version 在领取页尝试时增加一次。来源/文档/索引与终态游标仍共同提交，终态使用该 attempt version，但必须完整匹配领取身份、原游标全部状态及未过期租约，并重新检查实际用户/项目/配置。随机身份和完整状态比较防止同版本终态阶段被当作另一执行。失败只记录静态代码，释放领取；成功和失败均不遗留活动租约。

取消、禁用、重置和配置失效会变更游标并清除领取。旧 Reader 结果及异常清理不能覆盖新游标。启动/状态协调对过期读取保存新的失败版本，保留原分页边界和最后成功观察，后续用户可继续读取；活跃租约在过期前不擅自重领。数据库重开保留领取。取消阻止提交，仍不能直接中断已发出的 HTTP 请求。

读取后实际权限丢失时不提交来源或 Provider 失败观察。内部清理仅允许释放那一个先前已授权且仍完全匹配的领取，记录安全的 authority_changed 状态；不代理新观察、不恢复权限，也不处理替换执行。来源提交/审计故障回滚全部资料变更，单独保留或结算读取领取供恢复。写入器故障下保留租约，原始错误不被清理错误覆盖。

资料页显示正在读取，读取期间按秒刷新状态，取得最新版本后可取消第一页；没有活动读取时停止轮询。完整同步水位和事实/共享确认规则不变。
