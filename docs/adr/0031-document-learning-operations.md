# ADR 0031：资料学习的重试、续租与本人运行提示

状态：接受（本地 SDK 抽取、单进程协调器）。

学习任务继续使用现有持久 Job、lease epoch、三次尝试和独立 token 预留。SDK 隐藏重试保持关闭。暂时失败读取 Provider 的 Retry-After 秒数或 HTTP 日期，亦支持仅有 retry-after-ms 的响应；下次时间取本地退避和 Provider 要求的较晚值。非法或过去的时间使用原退避，超过一天的等待转为 blocked，不缩短为自动提前重试。响应正文、任意错误消息和凭据不保存。

实际等待抽取期间每 30 秒续租，整次抽取继续受原 90 秒期限控制。续租在写事务中验证当前 lease epoch/attempt/未过期租约，以及来源、actor/project 权限、模型选择、学习 opt-in 和偏好版本。失效租约不得复活；政策或来源变化取消该次等待，结果不能生成候选。未报告用量的预算仍完整预留，续租本身不增加尝试或预留。

现有本人 learning/status 增加只读运行投影：当前可访问项目的就绪、执行、重试、失败、blocked、过期租约和未报告尝试数，以及今日预留与 cap、遗忘清理积压。SQL 聚合不加载 job/source 正文；actor 和项目权限来自同一事务。重试等待时间未到不计入就绪积压，队列 age 从实际到期时间计算。就绪等待五分钟、过期租约、当日预留达到 cap、清理等待一分钟及终止尝试用量未知生成静态提示。正常执行中尚未返回用量不触发该提示。

“资料学习与待确认记忆”展示这些本人范围的计数和提示，启用学习或仍有清理积压时刷新。旧响应未提供队列时不编造健康状态。告警只显示在本人页面，不发送消息，不自动修改 Task 或共享 Memory。

确定性回归包含真实异步等待续租/取消、过期及不同 epoch 拒绝、Provider 时间、晚到来源变化、预算保留、到期排队和当前权限过滤。它验证控制流程，不代表真实 Provider 质量或企业联调。见 `docs/verification/2026-10-06-document-learning-operations.json`。
