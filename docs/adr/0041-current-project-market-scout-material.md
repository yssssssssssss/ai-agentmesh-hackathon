# ADR 0041：匹配 Agent 的当前项目材料与逐次发送检查

状态：接受（普通私人材料资格与原生来源；完整 SDK 预算、外部来源及统一上下文继续开发）。

旧 scout 在读到信号项目前汇总本人所有项目材料，未检查 archived_at、私人 scope、绑定、当前私人 Agent 或原生来源。归档时间已设置但 status 仍 active 的材料、其他项目材料和绑定禁止的材料确实进入模型提示词。普通查询无界遍历并 hash 所有材料，再只发送前 50 个标题。模型后检查也不能阻止领取任务后撤权的发送，且 NO 判断会跳过来源复核。

`MarketScoutMaterials` 为每条信号的显式项目准备一个只读快照，复核当前活跃 User、同工作区 Project 的成员资格、在线且归属于该用户的私人 Agent、绑定及启用的模型定义。材料限定本人私人 scope、当前信号项目或全局私人项目、active 且未归档的普通 Memory。结构化事实/过程继续由各自上下文处理，未知敏感等级不进入匹配。绑定收窄项目、私人 scope、记忆类型和数量。

查询使用已有授权搜索 SQL，以最多八个问题关键词分别执行 FTS/中文短词回退，并去重最多 32 个材料候选；每个 SQL 搜索仍有既有 200 元数据候选上限。按当前 scope/type/lifecycle 过滤之后读取载荷；并非只取最新材料，64 条新无关记录之后的旧相关材料仍能召回。选中最多八条 Memory（也受绑定结果上限约束）和八条当前项目、本人活动 Thread 的 Task。Task SQL 先限定关键词、项目和归档资格，再取最多 32 条候选。

Memory 载荷最多 32,000 字符，Task 载荷最多 65,536 字符，单条材料最多八个 Source。匹配请求仅发送每项最多 120 字符的标题，不发送 Memory summary、来源正文或私有 ID。求助文本最多 800 字符并检查不安全内容；无合格材料则不发模型请求。已知 high 材料只作为本人模型的标题线索，后续代答仍走现有本人确认网关，不建立新共享授权。

冻结证明包含当前 User/Project/Agent/Binding/Model、实际选中 Memory/Task/Thread 的完整记录，以及原生 Document/父 Memory 的私有 canonical hash。原生文档版本、所有者、项目、撤回和载荷身份均检查；来源证明最多 64 个记录键，父链使用已有四层上限。共享父节点在同一不可变读快照中复用已证明结果，避免重复展开。完整文档记录 hash 阻止正文或元数据变更但版本未递增时接受旧模型判断。

原生 `document_import` 普通分块还需拥有可解析的版本化 chunk 位置，并与当前文档按既有 chunker 生成的对应分块完全一致（文档文本上限沿用 1MiB）。这同时保护首次读取：正文被直接改写而版本不变时，不能通过重新准备快照把旧分块变为当前证据。既有结构化事实/过程继续使用自己的证据与适用性协议。

每个实际匹配模型调用之前复核当前证明、信号、用户/项目/参与资格、模型身份及持有的 matching claim。主模型失败后备用模型也重复检查；包装不修改共享 client。模型返回后，YES 和 NO 都复核同样的状态，再决定是否交付或记录 no_match。已到期或被接管的 claim 不交付判断；撤权、来源改变或过期进入既有 retry_wait，并保留错误状态。没有更改既有十分钟 matching lease、180 秒模型默认超时或确认策略。

匹配策略版本更新为 `market-matching-v3-scoped-qualified-material`，旧回执通过既有 fingerprint 机制重新判定。备用模型的声明身份也纳入 fingerprint；只保留 hash，不公开私有材料身份。Receipt/Cursor/Inbox/Consent 继续使用已有持久记录，未新增队列或 Runtime。

验证记录见 `docs/verification/2026-10-06-current-project-market-scout-material.json`。当前确定性匹配专项 **46 passed**（新增 24 个资格/源变化/发送/回退/租约/召回场景）；Python 3.12/3.13 各 **347 passed** 关联回归和 **74 passed** 无重叠的导入/恢复/学习/遗忘补充回归，合计各 **421 passed**。Ruff/diff 通过；HTTP/存储模型合同和前端控件未改变，没有重跑整个后端或真实 Provider。本项没有证明真实模型匹配质量、完整输入/输出 token/成本/取消预算、外部 Source 版本/hash/墓碑或 SDK/Runner 全部对齐，阶段 3–5 保持实施中。
