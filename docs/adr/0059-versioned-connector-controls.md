# 0059：连接器的版本化禁用、重置与取消

日期：2026-10-07。状态：手动控制已实现，后台生命周期继续开发。

复用 ConnectorSyncCursorV1 增加 enabled、disabled/cancelled 状态。控制命令在同一 SQLite 写事务重新检查实际用户/项目权限、游标的 owner/workspace/project/provider/namespace 身份和预期版本；游标、来源失效及审计共同提交。既有游标默认启用，不新增 durable entity。

入口为 `POST /api/projects/{project_id}/connectors/{cursor_id}/control`，请求包含 expected_version 和 action：

- disable：来源标记 unavailable，停止后续同步。保留历史镜像和最后读取时间，不能继续用于当前检索或引用。
- reset：先使旧来源失效，清空分页/水位/完成标记并启用同步；绑定服务端当前的同一 provider/namespace 配置，下一轮完整读取。重置本身不恢复来源。不同仓库 namespace 使用新游标，不静默改写原身份。
- cancel：保留已有观察，清空本轮分页并更新版本。正在读取的旧页因版本不匹配不能提交；下一轮完整读取。

GET 状态合并当前配置和本人历史游标，标明配置移除或配置摘要变化。没有配置的旧连接器仍可禁用和取消；重置必须存在匹配的实际配置。Knowledge 提供对应操作，禁用后不提供同步按钮，恢复显示“恢复并重置”，重置后显示等待同步。同步等待期间已有游标可发出取消/禁用命令。

42 个直接关联后端检查通过，覆盖禁用后的引用失效/拒绝同步、旧版本拒绝、重置后需重新观察、配置更换、读取期间取消、配置移除后可管理，以及实际主体停用后的拒绝。前端状态/操作检查、API 类型和构建另有证据记录。本轮未重复完整回归、双版本回归、真实 Provider 或浏览器验收；前一切片真实读取证据不替代这些新控制的检查。

限制：取消阻止提交，不能立即中断已发出的 HTTP 请求；首次同步在第一页提交前尚无持久游标，当前控制入口不能取消该页。配置移除只是保留可管理状态，仍需用户显式禁用；自动来源失效与部署启动协调待完成。后台限速/重试/租约/取消、完整外部 ACL/删除发现、观察时效和完整 Session/Runner/Artifact 血缘继续实施，整体阶段不标记完成。
