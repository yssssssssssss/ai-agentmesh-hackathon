# ADR 0037：自动协作摘要的当前授权与原子发布

状态：接受（自动发布提交、退出及本人遗忘撤回；统一来源治理和 SDK 调用治理继续开发）。

旧发布在读取资料后等待模型，随后直接 upsert；等待期间退出市场、移出项目、归档/更改记忆或关闭绑定仍会发布旧输出。高敏、其他项目的普通文本和已撤回文档也可能进入发布模型。新增的十二个回归场景均实际复现旧问题。

MarketPublishingService 复用现有 User/Project/Agent/MarketParticipation/Memory/Task/Blackboard/Audit，不新增 Runtime 或独立 durable entity。当前 active 身份、active 同 workspace 项目成员、online 本人 PersonalAgent、明确 opt-in、MemoryBinding 和未禁用模型先于材料读取。只选本人当前项目或无项目的 private、active、未归档、normal 纯文本；事实、过程、私人代答、个人汇总/归档载荷不自动成为公开材料。原生文档要求可核对的版本 reference 和当前 origin，旧无版本资料须重导入。

每类最多检查 32 条候选，最终最多八条 Memory 和八个当前项目本人 Task 标题；Memory 标题/摘要分别最多 120/2,000 字符，来源最多八个，总 Memory 标题正文最多 16,000 字符，Task 标题最多 120。超界材料整体跳过。项目/线程/Task 当前 scope 在 SQL 中过滤。这里是明确的字符/记录边界，不声称为完整 SDK tokenizer 或累计 token 预算。

快照 hash 覆盖当前身份、项目、Agent、参与水位、绑定、模型定义、选中完整记录及前一条自动信号。模型 client 解析后、实际发送前重查；输出提交在 BEGIN IMMEDIATE 内再次读取与比较。版本未递增但选中记录内容改变也会阻止发布。前一信号的比较防止慢输出覆盖更早完成的新发布，不保证并发模型请求只发生一次。

输出必须为“能力/可提供/需要”三行，各值最多 800、总体最多 2,400 字符，并通过现有危险内容/凭据检查。不合格模型输出不改成模板后发布。没有模型或调用失败时，仍可由合格标题生成明确的协作信号。信号、FTS/vector pending 和审计同事务提交；索引错误整体回滚，后续可干净重试。公共 metadata 只保存范围及 opaque hash，不写入私人 Memory ID/正文证明。

退出市场在同一参与写事务内撤回该用户唯一的自动信号，清空正文并删除 FTS、向量及向量状态；重复退出也会清理遗留输出。本人遗忘记忆/撤回资料的屏障事务保守清理该聚合信号，不猜测其私有来源。未来 tick 只能重新选择剩余合格材料。管理员不借此代替用户发起遗忘，已有用户/项目成员读权限仍由原接口校验。

ADR 0036 的四个读取 API 增加可选 project_id，明确请求的项目仍检查当前成员；省略时读取当前持久默认项目。市场图、动态、board、status 的查询缓存都含项目，请求也携带该项目，避免异步请求或切换复用别的项目结果。退出/遗忘刷新市场缓存。界面解释普通材料摘要、高敏排除及未启用自动运行；数量称为回应/匹配记录，等待或未交付不算已完成解答。

双版本完整快照各 **2,400 passed / 5 个既有 PyMuPDF 警告**，包含当前全部后端发布、读取、撤回修改；前端最后的 board 缓存及文案另行验证，**236 passed / 47 files**，生产构建/bundle、OpenAPI、Ruff/diff 通过。Ego Lite 的独立临时库实测本人摘要、其他 workspace 隔离、实际退出及刷新恢复，桌面截图已检查。具体专项和边界见 `docs/verification/2026-10-06-current-authority-market-publication.json`。

本切片不完成统一 SDK 请求、模型用量/交付回执、未知成本、可取消期限或 failover 治理。通用外部来源、普通归档及其他变更的已有信号失效传播仍需统一来源层；本次已有信号撤回明确覆盖退出和本人遗忘/资料撤回。未验证真实企业读取、真实模型摘要质量或启用向量 Provider 的容量/交付。完整阶段 3/4/5 继续开发。
