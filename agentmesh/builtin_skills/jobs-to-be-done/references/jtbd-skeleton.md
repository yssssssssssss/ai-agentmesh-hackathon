## 一、一句话结论（放最前，结论先行）

```
# JTBD 需求定义：[一句话复述本次要挖的需求 / 功能]

**核心 Job**：当 [触发情境]，用户想 [完成什么任务]，以便 [达成什么结果]。
**需求本质**：[「XX 功能 / 诉求」不是用户真正要的；用户要完成的是上面这个 Job，它只是其中一种解法 / 命中了其中的 X 层]。
**结论**：[该做 / 缓做 / 换个解法 / 先验证] —— [一句理由]。

> 证据基础：[基于 N 份/位 材料 · 或 · 无用户材料，本篇为待验证的 Job 假设]
```

## 二、需求解析（精简对照，不展开推理）

> 只给"原始需求 → 落到的 Job"这一步对照，加最多一两句点出关键转折。**不要**写"表层→中层→深层"的逐级追问，**不要**加理论旁白。

```
## 需求解析

- **原始需求**：[原样复述]（形态：解决方案层 / 表层诉求 / 已接近 Job）
- **落到的 Job**：[一个动词 + 一个对象、不含产品名]
- **关键转折**：用户要的不是「[原始需求字面]」，而是「[Job 的实质]」。[如需要，再补一句为什么——一句为限。]
```

写法约束：
- 有材料就在 Job 后挂一个来源标签（如 `[用户 A/C/E]`），无材料就标 `[假设]`——**只标签，不解释**。
- 爬到"不含产品名的 Job"才算到位；若还带产品 / 功能词，说明没爬够（这是你自查，不写进正文）。

```
## Job 定义

### 核心 Job
- **Job Statement**：当 [情境]，我想 [动词+对象]，以便 [结果]。
- **相关 Job**：[Job 1] · [Job 2] …

### 三层维度（"标注"列只填短标签：`用户A,C` / `假设` / `证据不足`，不写整句解释）
| 维度 | 内容 | 标注 |
|---|---|---|
| **功能层** | [要客观完成的操作 / 结果] | [来源 / 假设] |
| **情感层** | [内在感受：安心 / 掌控 / 不焦虑 / 不被打扰…] | [来源 / 假设] |
| **社会层** | [在他人眼中想成为 / 被如何看待；不显著就写"本例不显著"] | [来源 / 假设 / 证据不足] |

> 情感 / 社会层填不出且无材料支撑时，直接写"证据不足，待访谈补"，不硬编、不解释为什么填不出。

### 触发情境
- **When / Where**：[什么时候、什么处境下触发]
- **Who**（情境角色，非人群标签）：[使用者 / 提出者 / 影响者]
- **Why**：[为什么此刻产生]

> 若情境有明显分叉、对应不同候选 Job，直接分列 A/B 两个候选 Job（一句话各一个），并标"哪类为主需先验证"——不并成一个。

| 阶段 | 用户在这一步做什么 | 痛点（耗时/麻烦/易出错） | 什么算做好 |
|---|---|---|---|
| [阶段1] | [……] | [……] | [……] |
| … | | | |
> 高频痛点集中的阶段 = 机会点候选（见下）。
```

## 十、形态示意（示范"精简正文长什么样"，**勿照抄内容**）

> 下例凭空编，只示范写法：正文全是结果、无理论旁白、无内联引用、假设只用短标签。看完格式即弃。

```
# JTBD 需求定义：给外卖 App 加一个"收藏这家店"功能

**核心 Job**：当一天忙完、又累又不想动脑时，用户想快速搞定一顿吃得放心的正餐，以便尽快从"饿+累"里解脱、把精力留给休息。
**需求本质**："收藏店铺"只是解法，命中的是"降低每次重新决策的心力"这一情感层；用户要的不是收藏夹，是"不用每次重新纠结吃什么"。
**结论**：换个解法——"一键再来一单"可能比"收藏夹"更命中 Job；先验证复购占比再定。

> 证据基础：无用户材料，本篇为待验证的 Job 假设。

## 需求解析
- 原始需求："加个收藏店铺的功能"（形态：解决方案层）
- 落到的 Job：在疲惫时低心力地搞定一顿放心正餐　[假设]
- 关键转折：要的不是"能收藏"，而是"少做一次选择"。

## 竞争格局
| 替代方案 | 品类 | 功能层 | 情感层 | 一句点评 |
|---|---|---|---|---|
| 重复上次的订单 | 同品类 | 高 | 高 | 零决策，情感层完成度最高 |
| 自己做 | 跨品类 | 中 | 低 | 更累，与"省心"背道 |
| 泡面/囤的速食 | 跨品类 | 中 | 中 | 应急可用 |
| 什么都不做/随便对付 | 不作为 | 低 | 低 | 也是真实选项 |
```
> 注意：全篇没有一句"根据梯子理论""（用 user-needs 三层）"这类话，也没有把追问过程摊开——只有结论。方法论去运行说明看。**形式照此，内容按真实需求重写。**
