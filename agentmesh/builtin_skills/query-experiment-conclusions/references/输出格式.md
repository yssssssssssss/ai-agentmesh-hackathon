# 输出格式

skill 反查后展示给用户的**极简结构化输出**。

## 核心原则

**直接给结论 + 数据 + 链接 + 建议,不啰嗦。**

- ✅ 给一句话直接答用户的问题
- ✅ 给关键数据(核心指标即可,不必 P0/P1/P2 全列)
- ✅ 给强相关实验的 HTML 预览链接(优先)+ md 链接(备选)
- ✅ 给 1-3 条基于实验的建议
- ❌ 不写"命中原因"(用户不 care 打分逻辑,点开链接一眼就懂)
- ❌ 不展开"慎用条件"独立小节(合并到建议里,或省略)
- ❌ 弱相关**只列标题 + 链接**,不写数据、不写一句话结论
- ❌ 不重复实验的背景、方案说明(用户想看点链接)

## 标准模板

```
🎯 结论:{一句话直接回答用户问的问题}

📊 关键数据:
   {P0 指标}: {P0 数据}
   {P2 指标}: {P2 数据}   ← 只在有辅助数据时列;P1 落地经验类不必列

📄 参考实验:
   {结论 emoji} {落地建议 emoji} 《{实验标题}》
   🌐 [预览页(HTML)]({html_url}) · 📄 [md 源码]({md_url})

💡 建议:
   - {建议 1}
   - {建议 2}
```

**说明**:
- emoji:✅ 正向 / ❌ 负向 / ⚪ 无差异 · 🚀 全量上线 / 🎯 分人群上线 / 🔄 迭代优化 / 🚫 废弃方案
- HTML 链接放前面,md 链接备选
- 建议 1-3 条,不要凑数
- 单次总长度控制在 **250-400 字**(强相关只 1 个时)/ **400-600 字**(强相关 2-3 个时)

## 失败实验(负向 / 废弃)

顶部加醒目警告,数据和链接照样精简:

```
❗ 历史失败 · 参考避坑

🎯 结论:这个方向历史上做过并失败了,不建议抄。

📊 数据(负向):
   {P0 指标}: {P0 数据} ❌

📄 失败实验:
   ❌ 🚫 《{实验标题}》
   🌐 [预览页]({html_url}) · 📄 [md]({md_url})

💡 建议:{建议怎么做,或"参考相关正向实验:XX"}
```

## 多个强相关(top 2-3)

标题下重复"参考实验"卡片区,数据和结论合并到一段:

```
🎯 结论:{综合结论,一句话}

📊 关键数据 & 参考实验:

   ✅ 🚀 《{标题 1}》 · P0 {数据}
   🌐 [预览]({html}) · 📄 [md]({md})

   ✅ 🚀 《{标题 2}》 · P0 {数据}
   🌐 [预览]({html}) · 📄 [md]({md})

💡 建议:
   - {建议 1}
```

**不要**为每个实验单独写"关键数据"小节 — 挤在一行内。

## 弱相关折叠区(可选,极简)

只在**有 3 个以上弱相关**且用户可能感兴趣时才展示。**只列标题 + 链接**:

```
▸ 相关但匹配度较低的实验:
   · 《{标题}》 → [预览]({html})
   · 《{标题}》 → [预览]({html})
```

不写:数据、结论、命中原因、落地建议 emoji。

弱相关 ≤ 2 个时,直接省略整个折叠区。

## 完全没匹配

```
🕳 没找到强相关实验。

已有实验分类:
  · 📇 商卡:{N} 个 → [看全部]({商卡.html})
  · 📐 腰部楼层:{N} 个 → [看全部]({腰部楼层.html})
  · 🎚 父子嵌套:{N} 个

建议:换个描述再试,或先做方案、上线后录入。
```

## 引导补问

用户提问太宽泛,补问一轮:

```
🤔 匹配到的都是弱相关,能补一点信息吗?

{针对性问题}
  [a] {选项}
  [b] {选项}
  [c] 其他:___

回答后我再筛选。
```

## HTML 链接生成规则

**预览页(优先)**:
```
$BASE/_knowledge/experiments/previews/{分类}.html#{缩写}
```

**md 源码(备选)**:
```
$BASE/_knowledge/experiments/{分类}/{缩写}.md
```

URL 里的中文和空格必须 encode(空格 → `%20`,中文 → `%XX`),否则 VSCode 打不开。

例:
```markdown
🌐 [预览](../../_knowledge/experiments/previews/%E8%85%B0%E9%83%A8%E6%A5%BC%E5%B1%82.html#%E6%A5%BC%E5%B1%82%E6%B0%9B%E5%9B%B4)
```

## 例子 · 真实输出模拟

### 例 1 · 用户问"腰部楼层加氛围背景能提升点击吗?"

```
🎯 结论:不能。历史实验数据显示氛围背景对点击基本无影响(+0.01pp),
        反而"去氛围、突出利益点"被验证为可复用经验并全量上线。

📊 关键数据:
   页面 CTR: 67.76% → 67.77%(基本持平)
   页面 CVR: 7.01% → 7.04%(+0.03pp,轻微正向)

📄 参考实验:
   ✅ 🚀 《腰部楼层氛围 vs 无氛围》
   🌐 [预览页](../_knowledge/experiments/previews/%E8%85%B0%E9%83%A8%E6%A5%BC%E5%B1%82.html#%E6%A5%BC%E5%B1%82%E6%B0%9B%E5%9B%B4) ·
   📄 [md](../_knowledge/experiments/%E8%85%B0%E9%83%A8%E6%A5%BC%E5%B1%82/%E6%A5%BC%E5%B1%82%E6%B0%9B%E5%9B%B4.md)

💡 建议:
   - 不要为了拉点击加氛围,数据不支持
   - 想优化腰部楼层,方向应该是简化视觉、突出利益点
   - 大促/首焦等高势能资源位另论,不能直接套用
```

### 例 2 · 完全没匹配

```
🕳 没找到强相关实验。

已有实验分类:
  · 📇 商卡:2 个 → [看全部](../previews/%E5%95%86%E5%8D%A1.html)
  · 📐 腰部楼层:1 个 → [看全部](../previews/%E8%85%B0%E9%83%A8%E6%A5%BC%E5%B1%82.html)

建议:换个描述再试,或先做方案、上线后录入。
```

## 边界

**skill 输出时严格遵守**:
- 不加原创解读("我觉得...")
- 不组合多实验数据得出新结论
- 不推理未验证结论("如果加 XX 可能会...")
- 失败实验必须加 ❗ 警告
- 建议要**具体、可操作**,不要凑虚话
