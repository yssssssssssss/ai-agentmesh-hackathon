# 竞品分析 · 输出骨架与模板

> 本文件是 **competitive-analysis skill 自己的产出结构**，不是 wiki 正典。
> 战略意图四问的问法、AARRR 五环节的定义与典型功能、SWOT 用法、用户体验五要素的分层、打勾对比与跟进决策矩阵的口径等正典内容**一律运行时从 `research-wiki/` 现读**（见 SKILL.md 第 2 步），不在此复制。
> 下面方括号 `[…]` 是占位槽，按本次 brief、读到的正典、以及用户提供的真实竞品素材填实。**严禁脑补竞品**：竞品的功能/页面/策略/数据都要有素材出处；**战略意图一律以「推断」落笔**，不写成竞对官方事实。

---

## 一、直接分析模式 · 输出骨架（有竞品素材时，默认）

开头先用一句话交代：**分析对象（哪些竞品）/ 我方产品与阶段 / 分析目标 / 素材形态（功能观测·截图·策略·评价·描述）**。

### 0. 竞品分析结论摘要（结论先行，放最前）

```
- 一句话核心判断：[竞对在下什么棋 + 对我方最大的威胁/机会是什么]
- Top 3–5 应对建议速览（每条：竞对动作 → 跟进基调[必须回应/选择性优化/战略防御/忽略] → 一句怎么做）：
  1. [动作] → [基调] → [怎么做]
  2. …
```

### 1. 知己小结（先「知己」再「知彼」）

```
- 我方产品定位：[一句话]
- 生命周期阶段：[起步 / 成长 / 成熟] → 据此选宏观框架：[起步→机会与威胁 / 成长→创新亮点 / 成熟→体验细节]
- 核心用户特征：[谁在用、什么场景]
- 本次分析目标：[评审支撑 / 持续监控预警 / 起步验证 / 找创新亮点 …]
  > 标注：[知己信息哪些是用户给的、哪些是合理假设——假设的在此标一句]
```

### 2. 竞品分层范围

```
| 竞品 | 分层（核心/重要/跨界） | 为何纳入（与本次目标的关系） |
|---|---|---|
| [竞品A] | 核心（直接竞争） | [产品形态/商业模式/目标用户高度重合] |
| [竞品B] | 重要（间接竞争） | [解决同类需求、形态不同、增速快] |
| [竞品C] | 跨界（灵感来源） | [跨行业但流程/体验可借鉴] |
> 别贪多：重点竞品重精力，其余略。分层与选品标准取自 competitive-analysis.md。
```

### 3. 读懂意图 · 战略意图四问（核心产物，每个值得关注的动作走一遍）

```
#### 动作 1：[竞对做了什么——基于素材的客观描述，注明证据出处]

- **Q1 时机（为什么是现在）**：推断：[临近大促 / 顺应热点 / 数据承压 …——附依据]
- **Q2 场景（解决谁的什么问题）**：推断：[新/老/会员/全量 · 高频/低频 · 体验/变现]
- **Q3 动机（AARRR 撬哪个指标）**：推断：[对到 获客/激活/留存/裂变/收入 哪一环 + 为何]
- **Q4 市场（SWOT + 是否威胁核心）**：
    - 我方 SWOT（针对此动作）：优势[…] 劣势[…] 机会[…] 威胁[…]
    - 是否动我方核心奶酪：[是/否 + 哪块核心（如 3C/家电/物流/会员/价格心智）]

> 每条意图都是**推断**，不是竞对官方说法。证据不足的写「素材有限，暂判为…，需进一步观测」。
```

（如有 AARRR 环节-功能映射需要成表，按正典 AARRR 表的列自建；此处不写死正典内容。）

### 4. 用户体验五要素拆解 + 打勾对比（成长/成熟期产品）

```
按五层拆解核心竞品（颗粒度按项目定，不必都到「原子」）：
- 战略层：[产品定位/商业模式/平台各方关系]
- 范围层：[核心能力与主要功能]
- 结构层：[信息架构与分类]
- 框架·表现层：[页面模块-组件-元素]

打勾对比表（功能项 × 各竞品，逐格打勾）：
| 功能项 | 我方 | 竞品A | 竞品B | 判断（人有我无/人有我有/人无我有） |
|---|---|---|---|---|
| [功能1] | ✓/✗ | ✓/✗ | ✓/✗ | [重点关注「人有我无」] |
| … | | | | |
```

### 5. 结果解读 + 跟进决策

```
战略层次归纳（以某动作为例）：
- 短期战术：[见效快的直接目标]
- 中期战略：[强化的心智/能力]
- 长期布局：[更远的图谋]

跟进决策矩阵（对每个动作定应对基调）：
|  | 威胁我方核心 | 不威胁核心 |
|---|---|---|
| **值得跟进** | 必须回应：[#…] | 选择性优化：[#…] |
| **不值得跟进** | 战略防御：[#…] | 忽略：[#…] |
```

### 6. 差异化行动建议

```
- [针对「人有我无」的关键差距：我方要不要补、怎么补——结合自身特色做差异化，不是复制]
- [可落地的产品/运营/体验动作；要挖增长机会点则衔接 opportunity-research]
- （如需排序）叠加 issue-prioritization 给建议排 P0/P1/P2
```

### 7. 分析范围与未覆盖（诚实声明边界）

```
- 本次素材覆盖：[分析到了哪些竞品/功能/策略]
- 未能覆盖：[素材没覆盖的竞品/功能/流程 → 标「未覆盖」，不假装分析过]
- 靠推断的意图：[哪些战略意图判断证据偏薄、属推断，需进一步观测/情报佐证]
```

## 二、框架模式 · 输出骨架（无竞品素材时）

> 末尾必须**明确索要竞品观测素材 + 知己信息**：拿到后即可切到「直接分析」。

### 1. 知己清单（先要用户补齐）

```
请先补齐（不搞清这个，竞品分析方向会跑偏）：
- 我方产品定位？ 处在生命周期哪个阶段（起步/成长/成熟）？ 核心用户是谁？
- 本次分析目标是什么（评审支撑 / 持续监控 / 起步验证 / 找亮点）？
```

### 2. 竞品分层监控框架

```
- 核心竞品（直接竞争）：[选取标准]
- 重要竞品（间接竞争）：[选取标准]
- 跨界标杆（灵感来源）：[选取标准]
> 按目标选品：决策预警→品牌/品类/替代品；学习借鉴→品牌/品类/参照品（口径取自正典）
```

### 3. 战略意图四问清单 + AARRR 映射表 + SWOT 模板

```
四问清单（问法取自 competitive-analysis.md，运行时现读）：
- Q1 时机 / Q2 场景 / Q3 动机（AARRR） / Q4 市场（SWOT + 是否威胁核心）
AARRR 五环节-功能映射表：[按正典的环节与典型功能列，别默写]
SWOT 模板：优势 / 劣势 / 机会 / 威胁 四象限（我方 + 竞对各一张）
```

### 4. 用户体验五要素拆解清单 + 打勾对比表模板

```
五层各看什么（取自正典）：战略层 / 范围层 / 结构层 / 框架·表现层
打勾对比表模板：| 功能项 | 我方 | 竞品A | 竞品B | 人有我无/我有/无我有 |
```

### 5. 跟进决策矩阵模板

```
|  | 威胁核心 | 不威胁核心 |
|---|---|---|
| 值得跟进 | 必须回应 | 选择性优化 |
| 不值得跟进 | 战略防御 | 忽略 |
```

### 6. 给用户的素材索要

```
要直接帮你分析，请发我：① 要分析的竞品（1 个核心 + 若干重要/跨界）② 竞对的可观测信息（功能更新截图 / 页面 / 运营活动 / 价格·会员·补贴策略 / 用户评价 / 文字描述）③ 我方定位与所处阶段（知己）。
```

## 五、形态示意（仅示范「长什么样」，**勿照抄内容**——务必按真实竞品与素材重写）

> 下例是凭空编的格式演示，不是任何正典内容、不是真实竞品结论，也不针对真实项目。看完格式即弃。

```
本次分析：我方[某到家业务]（成长期，核心用户=一二线上班族），对比[竞品X/Y]，目标=评审支撑。素材=竞对功能截图+运营活动描述。

【结论摘要】推断竞对X在用「预售+社区自提」抢下沉市场的低价心智，直接威胁我方价格敏感用户。
Top 应对：① X 的「预售直降」→ 选择性优化（做我方擅长的确定性履约，不硬拼绝对低价）② …

【知己】定位=品质到家；阶段=成长期（选「找创新亮点」框架）；用户=图快图省心的上班族。

【战略意图四问 · 动作1：X 上线「9.9 预售专区」（据截图2）】
- Q1 时机：推断——临近季度大促、且 X 近期增长放缓，需低价拉新。
- Q2 场景：推断——面向价格敏感新客，变现让位于拉新。
- Q3 动机（AARRR）：推断——主要撬「获客/激活」，预售锁单也带「留存」。
- Q4 市场（SWOT）：我方优势=履约确定性；威胁=价格心智被侵蚀。动我方核心奶酪？——部分（价格敏感客群）。

【跟进决策】动作1 → 威胁核心×不值得硬跟 → 战略防御（强化「准时达+品质」壁垒，不陷入低价战）。

【未覆盖】仅两张截图，X 的会员体系未见素材，未分析。
⚠️ 本分析基于 draft 正典（competitive-analysis 当前 draft），战略意图均为推断，重大决策需结合行业情报复核。
```

> 注意上例如何**把每个动作走完四问**、如何**把意图写成「推断」而非事实**、如何**用跟进矩阵定应对基调**、如何**只基于截图证据不脑补**、如何**诚实标「未覆盖」**、如何**就地标 draft**——形式照此，内容必须按真实竞品与素材重新生成。
